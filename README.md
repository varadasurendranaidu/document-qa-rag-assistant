
# Document Q&A Assistant using RAG

A Python-based document question-answering prototype that
extracts text from uploaded documents, splits it into chunks,
retrieves relevant passages using TF-IDF similarity, and
returns source-grounded answers.

## Features

- Upload TXT, PDF, and DOCX documents
- Extract text and split it into overlapping chunks
- Retrieve relevant passages using TF-IDF and cosine similarity
- Return answers selected from document text
- Display source document names and chunk references
- Handle questions when no sufficiently relevant passage is found
- Interactive interface built with Streamlit

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- TF-IDF vectorization
- Cosine similarity
- PyPDF
- Python-docx

## Architecture

1. Document ingestion
2. Text extraction and preprocessing
3. Overlapping text chunking
4. TF-IDF indexing
5. Similarity-based retrieval
6. Extractive answer selection
7. Source display

## Installation

Python 3.10 or newer is recommended.

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/document-qa-rag-assistant.git
cd document-qa-rag-assistant
```

Create a virtual environment:

```bash
python3 -m venv .venv
```

Activate it on macOS or Linux:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

Open the local URL printed in your terminal.

## How It Works

The application extracts text from uploaded documents and
splits it into overlapping chunks. TF-IDF converts the chunks
into numerical representations. Cosine similarity ranks
chunks against the user's question.

The application then selects a relevant sentence from the
retrieved passages and displays the associated source.

## Limitations

- Retrieval is lexical and may miss semantically related wording.
- Answers are extractive, not generated by an LLM.
- Scanned PDFs may require OCR before their text can be retrieved.
- Similarity thresholds may need adjustment for different documents.
- Source chunk references are provided; PDF page-level citations
  are not implemented in this version.
